搞节奏 Windows · 足迹地理数据来源

世界地图与海外城市：Natural Earth，公共领域。
https://www.naturalearthdata.com/about/terms-of-use/
https://github.com/nvkelso/natural-earth-vector
采用 1:50m 国家/地区边界与 1:10m Populated Places；城市坐标和多语言名称离线打包。
中国世界统计归属合并 CHN / TWN / HKG / MAC；世界图几何保留来源细节，不构成任何权威边界声明。

Windows 中国地级地图与省级边框：CTAmap v2.0，2026-01-01 WGS84。Rui Cheng、Chiwei Xiao、Yanjun Wang、Yunfeng Hu。CC BY 4.0。
https://doi.org/10.5281/zenodo.22179207
https://www.shengshixian.com/pages/d35ae5/
https://creativecommons.org/licenses/by/4.0/
按六位区划代码关联历史收藏单元，简化多边形并保留四位坐标小数。重建入口为 windows/generate_footprints_prefectures.py。图片导出带有数据署名。

Windows 备用中国省级地图：geoBoundaries CHN ADM1（2019），Public Domain，原始资料由 geoBoundaries 和 Wikimedia Commons 提供。几何按目录省级编号映射，坐标保留四位小数。
https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM1/
https://commons.wikimedia.org/wiki/File:China_blank_province_map.svg
固定下载地址和原文件 SHA-256 随 footprints-atlas.json 提供，重建入口为 windows/generate_footprints_atlas.py。

历史中国城市目录：Supeset/China-GeoData 仓库（MIT License，Copyright © 2025 圈集）。
https://github.com/Supeset/China-GeoData
Windows 继续读取已有的离线地名、收集单元编号及坐标，用于识别存档。Windows 安装包内没有该历史来源的边界多边形。该名称和单元清单为足迹收藏口径。中国位置坐标用于标注足迹。
历史目录的数据版本与上游 SHA-256 见 DatasetManifest.json。

地图渲染在本机离线运行。

Windows 原生通知：PyWinRT 3.2.1（MIT License）。
https://github.com/pywinrt/pywinrt/tree/v3.2.1
