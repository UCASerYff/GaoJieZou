# 搞节奏 V4.11 · 晨光工作台

版本：4.11（build 12）

## 界面与导航

- 使用“今天、节奏、健康、足迹、乐园”五个顶部工作台，替代拥挤的右侧栏目。
- 节奏内保留专注、睡眠、习惯、琐事、长期目标、短期行动和统计；健康内提供今日、全部记录、统计趋势和快速事项。
- 睡眠、习惯、琐事、目标、健康记录、足迹到访与旅行编辑器统一为轻卡片布局，沿用原有校验、编辑、删除和保存逻辑。
- 乐园集中提供农场、牧场、钓鱼、图鉴、荒岛和旅行列车六个真实游戏入口。
- 旧通知和深链继续可用；新增 `gaojiezou://health/records` 打开健康全部记录。

## 数据与安装

- 现用业务资料、共享睡眠、健康与足迹数据库、设置、附件、游戏进度和钥匙串凭据继续沿用原路径。
- 不再提供完整资料备份、模块备份、每日自动快照或启动恢复入口，也不再声明备份文档类型。
- 安装脚本只核验并替换正式程序；不创建旧程序归档、恢复快照或回滚副本。失败时停止并报告，不伪造恢复结果。
- 安装包和源码不包含用户记录、私有附件、数据库、设置、凭据或备份。

- 工作台映射：所有旧栏目和深链仍有可达入口。
- 习惯补打卡：历史归属、统计、连续打卡、奖励去重、失败回滚与持久化。
