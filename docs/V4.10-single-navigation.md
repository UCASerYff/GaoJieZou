# V4.10：统一主导航

健康和旅行足迹直接使用搞节奏的主侧栏，内容区只显示当前选中的功能页。原功能中的记录、编辑、补录、搜索和撤销继续保留。

|主侧栏分组|功能|
|---|---|
|健康管理|今日概览、快速事项、喝水记录、睡眠记录、饮食记录、运动记录、体重记录、统计趋势|
|旅行足迹|地图、旅行、时间轴、常驻城市|
|奖励系统|农场、牧场、渔场、庄园图鉴、荒岛生活、旅行列车|

只保留一份应用侧栏、品牌标题和侧栏开关。荒岛生活和旅行列车沿用各自的存档、资源与货币；不会转换成节奏金币，也不重新发放已有奖励。体重隐藏偏好仍生效，隐藏时不展示原记录。

健康睡眠页与睡眠计时页共享同一份记录，记录或删除一次即可。既有记录身份、删除墓碑和结算去重保持原样。原健康、足迹链接继续进入同一搞节奏宿主，窗口重开后的新链接沿用进程级路由序列。

主窗口已打开时，连续外部链接由现有窗口接收；处理链接后不再重新打开另一个主窗口。冷启动或关闭主窗口后，链接仍可打开对应页面。此窗口路由修复只更新宿主程序，健康、足迹和节奏模块及小组件保持原构建。

本次导航改版沿用 4.10/build11，不再执行资料迁移或重新激活。实际界面、游戏入口和组件仍按新候选的受影响范围核验，旧嵌套导航版本的验收不替代本次核验。
