# V4.09 长期目标编辑

首次打开已有长期目标的编辑表单时，可能出现标题已变为“编辑长期目标”，输入栏仍为空或保留新建默认值的情况。这会使正常编辑无法保留完整预填内容。

本次用一个包含目标对象的编辑路由驱动表单，并为每次打开提供独立草稿身份。新建时使用空草稿，编辑时由当次选中的完整目标初始化；重新打开同一目标也重新读取该目标。保存仍使用原目标 ID，取消仍直接关闭表单，不写入记录。

资料格式保持 schema 11，沿用原资料路径、App Group 和钥匙串服务。奖励、计时、游戏结算、SharedSleep 协议及小组件内容计算不变。安装前备份并校验现有资料；旧程序以经过校验的压缩归档保留在不索引的回滚目录，避免展开旧程序成为重复入口。

已完成完整编译、严格签名检查及宿主/框架/小组件版本一致性检查；原团队和完整指定要求保持一致。正式安装后的首次实际编辑检查通过：一个已有目标的标题、原因、结果、当前值、目标值、单位、开始日期、完成日期和状态均与原记录一致，点击取消后整份资料逐项保持原值。

没有自动运行冒烟测试。原小组件任务的四次短计时及精确记录清理已完成，多实例实际内容一致性、正常移除与同 kind 重加已核对。重加实例通过数量与身份检查后移除；全部临时组件已清理，原有组件的位置保持不变。重加实例的完整文本未单独保存，详见 [后续实机核对](V4.08-widget-sync.md)。
