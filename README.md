# 搞节奏

独立 macOS 应用，包含专注、睡眠、习惯、健康、足迹、游戏场景和 WidgetKit 小组件。

当前发行版为 V4.11/build12「晨光工作台」：五个顶部工作台重新组织全部业务，统一记录界面，并提供健康全部记录与类型筛选。

## 下载与安装

从 [Releases](https://github.com/UCASerYff/GaoJieZou/releases/latest) 下载 `GaoJieZou-4.11.zip` 和同名 `.sha256` 文件。仓库保存源码，安装包作为 Release 附件单独发布。

1. 支持 macOS 14 或更高版本、Apple Silicon；暂未提供 Intel 版本。
2. 解压 ZIP，将 `搞节奏.app` 拖入“应用程序”文件夹。
3. 如果 macOS 拦截打开，请先确认软件来源，再进入“系统设置 → 隐私与安全性”，允许该应用打开。发行包使用 Apple Development 签名，未做 Apple 公证。
4. 安装后运行一次，再从系统小组件列表添加本应用的小组件。整合版的小组件需要重新添加。

下载后可在文件所在目录运行 `shasum -a 256 -c GaoJieZou-4.11.zip.sha256` 核验安装包。发行文件使用英文名称，便于命令行校验和下载。

## 功能

- 今天、节奏、健康、足迹、乐园五个工作台；旧通知与深链继续打开原业务。
- 专注计时、手动睡眠、习惯、琐事、目标、统计及统一轻卡片记录窗口。
- 健康今日、全部记录、统计趋势和快速事项；全部记录支持类型、时间与搜索筛选。
- 关闭窗口后专注继续在后台运行；点击 Dock 图标或按 ⌘0 重新打开。⌘Q 会保存并暂停专注后退出；锁屏和系统睡眠仍按原规则暂停。
- 农场、牧场、钓鱼、图鉴、荒岛与旅行列车集中放入乐园。
- 从菜单或 ⌘, 打开设置，提供外观、模块设置和现用资料目录入口。
- 提供本应用对应的桌面/通知中心小组件。

## 用户数据、附件与隐私

源码及安装包不包含个人记录、账户配置、健康数据、私人附件、API 密钥、浏览器会话或用户备份。新电脑首次打开时创建自己的资料库；GitHub 下载不包含任何本机资料。

- 业务数据目录：`~/Library/Application Support/GaoSeries/Rhythm/`。
- 数据库或小组件镜像：`~/Library/Group Containers/5G96498KGJ.com.gaojiezou.rhythm/`。
- 设置保存在本应用的 UserDefaults 域；凭据由 macOS 钥匙串管理。
- 公开安装包会删除本机编译路径、源文件索引及扩展属性，再重新签名。签名证书的公开身份信息随软件发布，签名私钥不在仓库或安装包中。

真实业务历史完整保留。界面采用分页或归档减轻加载；游戏事件最多保留 300 条、抽取记录最多 200 条，累计收益、余额、保底计数、库存与游戏进度独立保存。

## 现用资料与升级

升级或替换应用程序不会删除业务历史、余额、库存、游戏进度、设置和附件；数据格式不变时继续使用原路径和钥匙串凭据。

V4.11 不提供或生成完整资料备份、模块备份和每日自动快照，也不会在启动时应用待恢复任务。健康与足迹保存只提交现用数据库和组件镜像；CSV、JSON 阅读导出保持可用。设置中的目录按钮只打开已经存在的目录，不会把缺失目录当成空白库创建。

## 从源码构建

需要完整 Xcode、Python 3 和 Apple Silicon Mac。默认脚本使用项目配置的开发签名身份；自行构建需使用自己的 Apple Development 证书，并相应调整签名团队、App Group 权限及小组件工程配置。

```sh
./scripts/build.sh
./scripts/package.sh
```

已激活的整合资料直接沿用原路径，V4.11 安装不运行迁移、快照或恢复步骤。不要用合成测试计划安装到真实资料目录。

通过环境变量 `GAO_SIGNING_IDENTITY` 可指定签名证书。修改团队后也需调整 `scripts/install.sh` 中的团队检查。`dist/` 存放本地发行 ZIP 和校验文件，不提交到 Git；上传到 GitHub Releases。

- `Sources/`、`Shared/`（如有）与 `Module.swift`：业务和游戏逻辑。
- `GameWorld/` 与 `Resources/`：场景、模型、贴图和其他资源。
- `Host/`：独立入口、设置和联动服务。
- `WidgetExtension/`：小组件；`Tests/`：回归验证。

## 版本更新

版本以 `Info.plist` 为准。后续功能改动仅更新受影响的应用，默认版本 +0.01、构建号 +1。只读核验用户资料后安装新程序并检查记录、附件和游戏进度，成功后清理旧程序、旧安装包、中间构建与已识别备份；不创建更新备份或回滚副本。程序资源与用户资料须分别处理，不能用清理构建目录的方式删除现用数据。

第三方组件和资源保留各自许可，详情见 `Resources/` 中的许可、来源说明与补丁记录。

## V4.01

修复关闭主窗口导致退出、专注中断的问题。关闭窗口后保留应用和计时进程，可由 Dock 或“文件 → 显示搞节奏”（⌘0）重开主窗口。明确退出时由应用层结算并保存，无窗口时同样有效；锁屏、熄屏和系统睡眠的暂停策略保持不变。

数据格式与路径不变。历史升级命令已经停用；当前版本只读核验资料，不创建更新快照或恢复副本。

运行 `./scripts/test_background_focus.sh` 验证无窗口计时、系统暂停/恢复、退出保存和重启恢复；测试只使用临时资料。

## V4.02 睡眠互通

在搞健康或搞节奏任一侧录入睡眠，另一侧自动显示，无需重复录入。两边运行时通过本机通知即时同步，并每 15 秒补查；关闭后下次打开同步历史和小组件。共享历史保存在健康 App Group 的 `SharedSleep/sleep-records.sqlite`，其余资料路径不变。历史 ID、睡眠时长、牧场结算标记全部保留，避免重复发奖；搞健康删除的睡眠也同步删除，已获得的奖励保留。搞健康新录入的有效睡眠在搞节奏同步时按原有手动睡眠规则补结算一次牧场。

## V4.03 菜单栏常驻

顶部菜单栏新增“节奏”图标，可查看后台状态、暂停/继续专注及显示主窗口。生命周期持续禁止自动终止，覆盖关闭窗口、待机和专注暂停阶段；显式退出、系统注销/关机以及锁屏休眠策略保持正常。重开主窗口的动作从实际窗口视图获取。

本地诊断日志位于 `~/Library/Logs/GaoJieZou/`，仅记录启动、退出、窗口和计时状态类型，限制容量并轮转，不记录业务标题。用以区分正常退出、退出请求来源与上次未正常结束。数据格式和路径不变。

## V4.04 补打卡

在「日常打卡」点击「补打卡」，默认查看昨天，也可选择更早日期，补记当天已安排且目标已创建的项目。完成记录归入所选日期，月历、完成率、连续打卡和 CSV 导出同步反映结果。每个项目每天只发一次金币；取消后再次打卡不会重复领奖。未来日期不允许补记，保存失败会恢复操作前状态。数据格式、资料路径和钥匙串服务不变。

## V4.05 睡眠录入秒开与预热优化

修复「睡眠计时」模块中点击「记录睡眠」首次弹出耗时较长的问题。手动录入睡眠界面重构为轻量高效的面板布局，移除了原生 Grouped Form 在模态弹窗中的重复尺寸测算与布局抖动；将系统日期格式化器改为全局基于语言复用与静态缓存，并稳定了日期选择器的有效区间约束。应用启动时在空闲周期自动完成预热，首次点开即可丝滑秒开。数据格式、资料路径及跨应用共享睡眠协议完全保持不变。

## V4.06 消除弹窗调度延迟与高频刷新隔离

彻底修复「睡眠计时」模块中点击「记录睡眠」弹出界面偶发严重延迟（十余秒）的底层根因。原实现中折叠面板内的睡眠计时器被包裹在每秒触发的 `TimelineView` 中动态变更 `DatePicker` 的有效时间区间与双向绑定，导致 AppKit 在调度模态 Sheet 呈现事务时与活跃的控件每秒重绘发生竞争与延迟；同时牧场动物面板与专注作物面板优化为仅在实际计时中才挂载每秒时间线刷新，非计时阶段完全静态渲染。此外将弹窗呈现路由迁移为与其他模块对齐的数据驱动枚举模式（`SleepSheetRoute`），彻底消除了弹窗调度超时与卡顿，实现毫秒级即时弹出。数据格式、资料路径与跨应用共享睡眠完全兼容不变。

## V4.07 手动录入弹窗应用内零延迟重构

针对 macOS 底层 AppKit 在弹出系统级物理 Sheet 子窗口时触发跨进程辅助功能树（`AccessibilityViewGraph`）构建超时导致首开 9 秒延迟的顽疾，重构为极致轻量的应用内现代浮动模态遮罩层（In-Window Modal Overlay）。彻底绕开 AppKit 的 `SheetBridge` 与子窗口物理会话阻塞，使点击「记录睡眠」首开即以首帧（约 20 毫秒）极速渲染展开，彻底消灭任何可感知的等待时间（真·零延迟）。支持完整的 ESC 快捷键关闭、点击半透明毛玻璃蒙层关闭、回车保存以及取消操作；完整恢复标准就寝日期选择器（`DatePicker`）。用户数据格式、资料路径及跨应用共享睡眠协议完全兼容且保持不变。


## V4.08 小组件同步

修复主库成功但镜像失败后丢失刷新待办的问题；后台闲置、唤醒、跨日及下次启动会重试。主库保存失败时取消正常退出以保留内存中的活动进度。小组件读取带校验和、资料时间与生成时间的原子快照，异常时保留有效旧快照或明确提示不可用，不读取其他备用目录或伪造零值。提前准备多日午夜时间线，活动专注按真实时间区间显示。

数据格式与资料路径不变，SharedSleep 协议不变。详细验证范围和跨应用同步限制见 [交付说明](docs/V4.08-widget-sync.md)。本次不自动运行冒烟或桌面界面验收。

## V4.09 长期目标编辑

修复已有长期目标首次打开编辑表单时，标题、日期等输入栏可能未正确回填的问题。每次打开均以当次目标初始化独立草稿，保存沿用原目标 ID，取消不写入记录。资料格式、奖励与共享睡眠协议不变，详见 [更新说明](docs/V4.09-goal-editor.md)。

## V4.11 晨光工作台

五个顶部工作台重新组织全部业务，记录窗口统一为轻卡片布局；健康新增全部记录、类型筛选与搜索，乐园保留六个真实游戏入口。完整说明见 [晨光工作台更新说明](docs/V4.11-morning-workspace.md)。

## V4.10 健康与旅行足迹整合

健康记录、事项、趋势、小岛，旅行地图、旅行历史、照片和列车，以及对应组件整合到同一个宿主。迁移保留原 ID、附件、进度和偏好；共享睡眠由单一权威保存，沿用删除墓碑与奖励去重记录。

健康与足迹的功能直接放在主侧栏，荒岛生活、旅行列车与原奖励游戏同级；内容区不再嵌入第二份应用侧栏。各游戏仍使用原存档和独立货币，详见 [统一主导航说明](docs/V4.10-single-navigation.md)。

迁移工具分为计划、准备、严格核验和激活；资料未激活时模块不会创建空白库替代原资料。Darwin 元数据复制使用显式、按计划绑定的精确政策，三份私有 SQL 临时库保留原 quarantine 字节。公开源码和发行附件不包含本机迁移计划、收据、原始元数据、个人资料或恢复副本。
